## Why

Read-only Pi children had an empty active-tool allowlist, so they could not inspect their own worktree or bundled Skills. The local autopilot-stack DAG did not produce the linear PR stack its name suggested, and newer upstream pstack behavior was still unmapped. This implements the first three follow-up priorities while preserving existing isolation and the reviewed baseline.

- Enable exactly confined file tools plus a safe bundled-Markdown registry and bounded parent-supplied evidence snapshots in read-only children; preserve missing-source uncertainty and recover packet state. Strengthen Poteto parent/delegate/fresh-task contracts.
- Add verified linear stack-plan/stack-open CLI commands, per-parent patch/ledger checks and idempotent ready-PR opening. Mark the existing DAG as local preparation. Add all-page review threads and conservative native Frontier snapshots, including pinned-trunk transitions and policy-bound approval digests.
- Port or explicitly map every one of the 35 pinned 0.15.23 changed files: new restatement Skill, ketchup/verification/Poteto/help rules, how/why references, audited plan-fence checker and explicit-base worktree audit. Preserve original reports and support content-addressed local mapping revisions.
