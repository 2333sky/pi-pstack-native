# Pi-native recipes

- Start a rigorous task with /poteto-mode plus a goal and observable pass condition.
- Ask /skill:in-your-own-words to restate your goal without starting implementation.
- Catch up with /skill:ketchup; this is read-only and does not resume jobs.
- Investigate with /skill:why. Parent supplies authorized evidencePackets for external sources; missing sources are reported unavailable.
- Local DAG planning is not a delivered PR stack. Prepare independently verified linear worktree branches, then run pstack-runner stack-plan and stack-open. Remote creation requires --approve; merging is a separate authorized action.
- /pstack-loop runs while the Pi session is active; it does not wake a closed process.
